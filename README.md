## Projeto em destaque

### Finance Insights: dashboard de finanças pessoais

Aplicação web que lê o extrato do banco (CSV ou OFX) e responde: quanto sobrou no mês, para onde o dinheiro foi, onde dá para economizar e quanto essa economia rende investida.

- Leitura de extratos de vários formatos, com categorização automática e regras que o usuário pode corrigir
- Nota de saúde financeira de 0 a 100, projeção do mês e relatório em PDF
- Simulador de investimentos com imposto de renda, inflação e taxas do Banco Central
- Lógica separada da interface e coberta por testes automáticos (pytest e GitHub Actions)

**Tecnologias:** Python, Streamlit, Pandas, Plotly, ReportLab e pytest.

[Ver o app](https://finance-insights-dashboard-telescode.streamlit.app/) · [Ver o código](https://github.com/Ctelesb/Finance-insights-dashboard)

## Outros projetos

### Sistema de venda de passagens aéreas

Plataforma simulada de venda de passagens, desenvolvida em **Node.js e SQLite**.

- Cadastro de companhias, trechos e passagens
- Consulta de voos, carrinho de compras e controle de estoque
- Cupons de desconto e validação das entradas
- Transações no banco de dados para manter os dados consistentes

**Tecnologias:** Node.js, JavaScript, SQLite e Git.
